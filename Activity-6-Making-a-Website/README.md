# Activity 6 
In this project, I conceptualized and developed a website prototype for "Labelled," a healthy meal-prep business centered on complete nutritional transparency. To accomplish this, I defined the brand's core objective—making healthy eating accessible and hassle-free through chef-cooked meals with clearly calculated calories, protein, carbohydrates, and fats—and used an AI web-building tool to generate the site from a targeted prompt.   Through this prompt-driven workflow, I built a nutrition-label-inspired web application featuring a home page, an interactive menu with dietary filters, full nutrition panels, a daily macro calculator, weekly meal plans, and a database-backed waitlist signup. Finally, I reviewed the generated interface and reflected on how clear nutritional labeling can empower users to make informed dietary choices without sacrificing taste or convenience.
